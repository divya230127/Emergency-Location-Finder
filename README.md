# Emergency Location Finder

A Flask-based emergency service finder that helps users locate nearby hospitals, police stations, pharmacies, fire stations, and clinics.

## Features

- Current location detection
- Location search
- Nearby emergency services
- Actual road distance in kilometers
- Near / Medium / Far classification
- Route visualization
- Color-coded routes
- OpenStreetMap integration
- OSRM road routing

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- OpenStreetMap
- OSRM
- Overpass API
